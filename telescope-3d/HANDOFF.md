# 굴절 망원경 만들기 3D 가이드 — 작업 인수인계

이 폴더의 `index.html`을 이어서 고쳐 주세요. 나(구인회, 중학교 과학교사)는 코드를 읽지 못하니, 수정은 Claude가 직접 하고 결과를 쉬운 말로 설명해 주세요.

## 만든 목적
- 매뉴얼(과학교사 노정현·구인회 제작, 4쪽 PDF)만 보고는 망원경 만드는 법을 이해하지 못하는 학생들을 위한 3D 가이드
- 교실 TV로 보여 줌 → 맨 뒷자리에서도 보이게 글씨를 크게

## 현재 상태 (1차 완성)
- 단일 HTML 파일, Three.js 0.160 (cdn.jsdelivr.net에서 불러옴), 빌드 과정 없음
- 공개 위치: claude.ai 아티팩트 https://claude.ai/artifact/8L81kWatiKxePi74qo7XcQ
- 스타일: "KEMI LAB 멀티미터" 시뮬레이션과 같은 방식 — 나무 책상 위 남색 커팅 매트, 왼쪽 위 FIG 라벨 박스, 오른쪽 위 PART/STEP 상태 박스와 TOOLS(도구) 목록, 3D 말풍선 라벨(라벨 버튼으로 켜고 끔), 아래쪽에 단계 버튼 패널과 HOW TO 설명 패널
- 색감: 검정 골판지, 파랗고 투명한 렌즈
- 조작: ←/→ 단계 이동, Space 다시 보기, L 라벨 켜고 끄기, X '속 보기'(골판지 반투명), 드래그 회전, 휠 확대

## 단계 (총 22단계, 매뉴얼 순서 그대로)
- 도안 1–8 (매뉴얼 4쪽): 골판지 놓기 → 점 찍기 → 긴 세로선 → 가로선 3개 → 가운데 칸 → 작은 칸 → 번호 쓰기 → 자르기(조각 16개로 분리)
- A 1–6 접안부: 선·양면테이프 → 비닐 벗기고 렌즈 2개 세우기 → 말기 → 절연테이프 한 바퀴 → 짧은 ② → 긴 ②
- B 7–10 고리 감기: ④+④ 잇기(가위) → ④ 감기(접안부엔 붙이지 않음) → ⑤ 이어 감기 → ③ 단단히
- C 11–14: ⑥ 경통 말기 → ⑧로 렌즈 틈 만들기 → 대물렌즈 넣고 말기 → 끼우고 목공풀(풀 O/X 표시) + 초점 맞추기(접안부 앞뒤로 움직임)
- 각 단계에서 연필, 50cm 자, 칼, 가위, 양면테이프, 절연테이프, 목공풀 도구가 애니메이션으로 움직임

## 도안 치수 (단위 cm, 골판지 39.4 × 54.5, 왼쪽 위 모서리 기준)
- 세로선 x = 9, 28, 32, 36 (전체 길이), x = 37 (위에서 18까지만)
- 가로선: 0–9 칸 y=30 / 9–28 칸 y=25 / 36–끝 칸 y=18
- 25선 아래 x=20 세로선, 왼쪽 y=38, 오른쪽 y=37 가로선
- x=25 (25~37), x=24 (37~끝), x=0.6과 4.8 (30~끝)
- 조각: ⑦ 9×30, ⑥ 19×25, ④ 4×54.5 ×2, ③ 1×18, ⑤ 레일 ×3, ② 11×13(짧은 것)·11×16.5(긴 것), ① 5×12, ⑧ 4.2×24.5 ×2, 나머지는 여분

## 상세 매뉴얼(사진 23장, `망원경 만들기 상세.pdf`)로 점검·수정한 것 (2차)
- ① 선 2cm·1cm, 절연테이프는 렌즈 가까운 1cm 쪽 → 사진과 일치 (그대로)
- 절연테이프 폭 0.8 → 1.9cm (사진 5). 렌즈 통은 이 테이프 부분만큼 ② 밖으로 튀어나오게 (사진 7·9)
- 고리 ④⑤: 접안부의 **눈 쪽 끝**(렌즈 통이 나온 쪽)에 감음 (사진 15·16). 전에는 반대쪽에 있었음
- ③: 고리 위가 아니라 **접안부(②) 바로 위, 고리 반대쪽 맨 끝**에 감음 (사진 18). 접안부가 빠지지 않게 막는 멈춤 턱
- ⑤: 짧은 ⑤ 2장(17.5cm씩)만 이어 씀 → 길이 35cm (사진 13·17). 도안 오른쪽 아래의 긴 ⑤(3.4×36.5)는 상세 매뉴얼에서 안 씀
- ⑥: 양면테이프를 ㄱ자(한쪽 옆 가장자리 + 끝)로 붙이고, 고리가 그 가장자리에 오게 놓고 말기 (사진 19)
- ⑧: 양면테이프를 길게 붙임 (사진 20)
- 완성 단계 초점 맞추기: 접안부를 눈 쪽으로 0~5.4cm 당겨 냄 (③이 고리에 걸릴 때까지)
- 양면테이프 폭 0.56 → 0.9cm (사진 2)

## 3차: 학생용 매뉴얼(`굴절망원경_만들기_매뉴얼.pdf`, 4쪽) 점검 + 비닐 벗기기 효과
- 양면테이프를 쓰는 모든 단계(A2·A5·A6·B8·B9·B10·C11·C12·C13)에서 "테이프 붙이기 → 비닐 벗기기(비닐 띠가 들려 올라감 + '비닐 벗기기' 말풍선) → 붙이기" 순서로 보여 줌. 공통 함수 `peelFx`/`peelL`
- 긴 ⑤(3.4×36.5): 매뉴얼 도안·부품표에 ⑤로 적혀 있어 3D 도안도 ⑤ 그대로 둠. 만들기는 상세 파일·매뉴얼 9번대로 짧은 ⑤ 2장만 사용
- ⑧ 양면테이프: 상세 파일 사진대로 길게 붙임 (매뉴얼 글 "양 끝에"와 다름 → 매뉴얼 글 수정을 제안함)
- 4차: B7에서 가위 제거. 완성(14) 단계는 원래대로 ⑦을 ⑥ 바깥에 씌움. 목공풀은 **감은 부분의 옆면(둥근 끝면) 3곳**에 차례로 바름: 눈 쪽(⑥+고리) → 접안부 바깥 감은 부분(② 끝면, 접안부와 함께 움직임) → ⑦ 뒤쪽 이음매. ⑦ 앞쪽 끝면과 렌즈 통, 고리 안쪽 틈은 풀 X. 옆면마다 카메라가 그쪽으로 돌아감(`cams`, `camTo`). 접안부(렌즈 쪽)는 풀 X
- 5차: 완성(14) 단계에서 목공풀 전에 **절연테이프 4곳**을 한 바퀴씩 감음(`TAPE_BANDS`): ⑥ 눈 쪽 끝 · ⑥ 이음매 앞 · ⑦ 이음매 뒤 · ⑦ 앞 끝. 상세 매뉴얼 사진 23처럼 파란색, 폭 1.9cm
- 6차: 절연테이프는 모든 단계에서 파란색. 왼쪽 위 제목 "굴절 망원경 만들기 3D 가이드"(단계 번호 FIG 문구 없앰), 아래 문구 "제작: 과학교사 구인회, 노정현"
- 7차 (v1.1): 휴대폰 화면 맞춤. 세로 화면은 3D 화면 위 + 설명(이전·다시·다음 포함)을 먼저, 단계 버튼은 아래(옆으로 밀어 넘김), 아래 패널은 화면 절반 이하로 줄이고 스크롤. 가로 화면은 3D 왼쪽 + 패널 오른쪽. 글씨·라벨·상태 박스를 작게. 좁은 화면에서는 카메라를 뒤로 빼서 옆이 잘리지 않게(`camZoom`). 터치 기기는 아래 안내를 "한 손가락: 돌리기 · 두 손가락: 확대"로. TV 화면(1920×1080)은 그대로
- 8차 (2026.11.22): 학생용 매뉴얼을 3D 가이드에 맞춰 고친 `굴절망원경_만들기_매뉴얼_수정.pdf`를 원본 옆에 만듦(원본은 그대로). 1~2쪽만 고치고 3~4쪽은 원본 그대로. 고친 것: 준비물에 연필·지우개, ② 크기(짧은 것 11×13·긴 것 11×16.5), ⑤ 짧은 것 2장, 5번(절연테이프 부분은 종이 밖으로), 7번(잘라 둔 ④), 8번(눈 쪽 끝), 10번(고리 반대쪽 끝), 11번(ㄱ자, 고리가 그쪽에), 12번(⑧ 양면테이프 길게), 14번 + '마무리 순서·목공풀 주의' 상자(절연테이프 4곳 → 감은 옆면·② 끝면에 풀, 접안렌즈 통·⑦ 앞 끝면·고리 안쪽은 풀 X), 14번 사진 라벨 '감은 옆면: 목공풀 O', 1쪽 오른쪽 위 3D 가이드 QR 코드와 아래 주소. 4쪽 모두 아래 표기를 "제작: 과학교사 구인회, 노정현"으로 바꿈. 원본 PDF의 원본 파일(HTML)이 없어 PDF 조각을 옮겨 붙이는 방식으로 만듦
- 9차 (v1.2): 매뉴얼에 맞춰 B8 설명 "접안부와 ④번 부품이 고정되지 않은 것이 정상이에요."로, '접안부엔 붙이지 않기' 말풍선 삭제. B10 설명 "③번 전체에 양면테이프를 붙이고, 접안부 맨 아래쪽(고리 반대쪽 끝)에 감아요.", 말풍선 '③ 단단히 고정'. 매뉴얼 8·10번 사진도 같은 내용으로 고침(10번 사진은 '③ 단단히 고정'이 접안부 위쪽 끝을 가리킴)
- 10차 (v1.3): 효과음. 소리 파일 없이 Web Audio로 만듦(`SND`): 연필 점·선, 칼, 양면테이프, 비닐 벗기기, 골판지 말기, 절연테이프, 목공풀, 렌즈 '팅', 툭, 스르륵, 완성 '딩동댕', 단계 넘김 딸깍. 단계마다 나는 때는 `SFX` 표(진행 0~1 기준). 오른쪽 아래 🔊 버튼·S 키로 켜고 끔(기본 켜짐, 브라우저에 기억). 브라우저 규칙상 화면을 한 번 누른 뒤부터 소리남. 점검용 `window.__snd`
- 점검용 `window.__seek(t)`: 지금 단계의 진행 위치(0~1)로 바로 이동
- 점검용 `window.__test()`: 22단계를 처음부터 끝까지 돌려 오류 목록을 돌려줌 (빈 배열이면 정상)
